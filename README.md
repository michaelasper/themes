# themes

Layouts and mods for the [Herdr app](https://herdr.dev), shared as [herdr.dev/layouts](https://herdr.dev/layouts) folders.

| Name | What | Preview |
|---|---|---|
| [conductor](conductor/) | Manage many agents from one session: manager terminal, flight-strip bays by what needs you, and a reader that follows the selection. Built for a voice/manager session; real data only. | ![](conductor/preview.png) |

`themes/dr-pepper.json` is the Dr Pepper Herdr theme the layouts use (also in [michaelasper/theme](https://github.com/michaelasper/theme)).

Each folder has `RECIPE.md`, `preview.png`, `install.sh` (copies new files only) and `uninstall.sh`.
